# CodeTestament candidate review

Reviewed: 2026-10-29

## Decision status

Update: Sean selected CodeTestament after this review and requested
[the rename and migration plan](codetestament-migration-plan.md). The original
research conclusion below records the screening boundary; selection does not
change the legal-clearance limits.

CodeTestament is the leading naming candidate following the user's favorable
response and request for focused trademark and similar-name checks. The suggested
product name is CodeTestament.Scorecard. No public rename has been authorized or
implemented. This review does not reserve names or establish legal clearance.

Product judgment: retain CodeTestament as the leading candidate. The searches
below found no exact-name product or federal trademark match. Nearby uses of
Testament deserve assessment, particularly the existing developer tools. Keep the
full CodeTestament name in branding and commands rather than shortening it to
Testament. This is a differentiation recommendation, not a conclusion about rights.

## Official US trademark searches

Queries were submitted through the USPTO Trademark Search interface using Field
tag and Search builder. Results were read after loading completed. No live/dead
filter was applied; both live and dead records were visible in the broader results.

| Query | Observed result |
| --- | --- |
| `CM:codetestament OR CM:"code testament" OR CM:"code-testament"` | No results found |
| `CM:(/.*code.*/ AND /.*testam.*/)` | No results found |
| `CM:(/.*(code\|kode).*test[aei]m.*/) OR CM:"code testimony"` | No results found |
| `CM:testament` | 149 results; used to identify nearby records, not all individually reviewed |
| `CM:testament AND IC:(009 OR 042)` | 31 results on one page; all result summaries reviewed |

The spelling query tests selected variants; it is not exhaustive phonetic or
similarity analysis. The first three searches had no class restriction. The last
search focused on classes 009 and 042 without treating class boundaries as a
determination of relatedness.

## Similar names in developer tools

- **Testament (Nim):** Nim's official documentation identifies Testament as its
  automated test runner, with multiple compilation targets, test statistics, and
  HTML reports. This is a real adjacent developer-tool use, although not the full
  proposed name.
- **Testament (Perl):** The `testament-testing-env/Testament` repository describes
  tooling for creating test environments and viewing module-test failures.

Exact-name and spaced-name web searches did not surface a CodeTestament product.
Selected spelling searches included Codetestiment, KodeTestament, and
CodeTestimony. Search absence is not proof that no use exists.

## Search limits and next decision

WIPO's Global Brand Database returned an access challenge. Its records were not
searched. EUIPO, UKIPO, CIPO, US state registers, business-name registers, and a
comprehensive unregistered-use search were not completed. A UK journal entry for
THE YOU TESTAMENT (UK00004359714, video-game goods) surfaced in web search; current
UK register status was not verified.

This is a focused US federal and public-marketplace screen, not worldwide legal
clearance. Before substantial public investment, a trademark professional can
assess the full CodeTestament / CodeTestament.Scorecard names for downloadable
developer software and any intended hosted service, including the Nim/Perl uses
and Fairyship Games registration above.
